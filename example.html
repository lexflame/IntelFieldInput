intelField: режимы инпутов

Одна реализация плагина поддерживает объединенные и раздельные группы, горизонтальную и вертикальную компоновку, а также контекстный поиск.

1. Объединенная строка, от 1 до 5 инпутов

Все сегменты выглядят как единый контрол. Между ними отображаются разделители, у каждого сегмента есть собственный dropdown. В режиме просмотра нет рамки и управляющих кнопок. Для изменения значения сделайте двойной клик по нужному сегменту.

2. Контекстный поиск

Dropdown фильтруется непосредственно при вводе. Поддерживаются стрелки, Enter, Escape, минимальная длина запроса и пользовательский matcher. Значение сохраняется сразу после выбора или при потере фокуса.

Введите запрос

3. Отдельные инпуты в одном блоке и одной строке

Каждый инпут сохраняет собственную рамку и dropdown, а общий блок располагает поля горизонтально. На узком экране они переходят в столбец.

4. Отдельные инпуты в одном блоке столбцом

Поля принадлежат одной группе, но располагаются друг под другом. У каждого поля независимые значение, состояние и список вариантов.

5. Выбор даты и времени

Дата и время объединены в один контрол с разделителем. Первый сегмент открывает календарь, второй — циферблаты часов и минут.

Дата и время не выбраны

6. Динамическое добавление и удаление инпутов

Кнопка «+» добавляет новую строку, а крестик удаляет выбранную. Единственный оставшийся верхний инпут удалить нельзя.

7. Одна кнопка добавления слева

Единственная кнопка «+» расположена слева от группы и открывает модальное окно. После подтверждения новый инпут добавляется в конец списка. У самих инпутов управляющих кнопок нет.

Добавить инпут?

Новый пустой инпут будет добавлен в конец списка.

8. Примитивы кнопок

Текстовая кнопка, checkbox-кнопка, раскрывающиеся действия Play и «Изменить», асинхронное сохранение и перенос с двойным Play.

Выберите действие

9. AJAX и PHP-коннекторы

AJAX-загрузка и адаптеры фреймворков подключаются отдельными файлами. Коннектор настраивает URL, параметры запроса, CSRF и формат ответа. 

$("#remote-field").intelFieldWithConnector("laravel", {
  search: { enabled: true, minChars: 2 }
}, {
  url: "/api/intel-field/projects"
});

// Ручная перезагрузка:
$("#remote-field").intelField("reloadItems", "проект");

10. Node.js и Vue.js

Node.js connector поддерживает Express, NestJS и Fastify API, Bearer-токены, cookie-сессии и произвольные JSON envelope. Vue 3 connector предоставляет компонент с v-model и директиву. 

$("#remote-field").intelFieldWithConnector("nestjs", {
  search: { enabled: true, minChars: 2 }
}, {
  url: "/api/projects",
  token: () => sessionStorage.getItem("access_token"),
  responsePath: "data.results"
});

app.use(IntelFieldVue, { Vue });
